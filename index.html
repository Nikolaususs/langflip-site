LangFlip

A Mac menu bar app that fixes text typed in the wrong keyboard layout.

Support

Questions, bugs or ideas: devesp2030@gmail.com

Getting started

  1. Add at least two keyboard layouts in System Settings → Keyboard → Input Sources.
  2. Open LangFlip and allow Input Monitoring when asked (System Settings → Privacy & Security), then reopen the app.
  3. Type a word in the wrong layout and press Control-Option-Space. The word is retyped in the right layout.

Common questions

Nothing happens when I press the shortcut. Check that LangFlip is enabled under Input Monitoring in System Settings → Privacy & Security, then quit and reopen LangFlip.

Automatic fixing does not work for my language. It uses the macOS spell checker. For languages macOS cannot check, such as Armenian or Georgian, add a Hunspell dictionary (.dic and .aff files) in Settings → Layouts. The shortcut works with every layout.

A word keeps getting changed when I don't want it to. Press the shortcut right after the automatic fix to undo it. LangFlip will leave that word alone from then on. You can edit the list in Settings → General.
